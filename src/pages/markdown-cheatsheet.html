Markdown Cheatsheet & Syntax Reference

This reference guide details all essential Markdown elements, GitHub Flavored Markdown extensions, tables, task lists, and mathematical formulas supported by MD Studio.

1. Headings

# Heading 1 (Page Title)
## Heading 2 (Major Section)
### Heading 3 (Sub-section)
#### Heading 4
##### Heading 5
###### Heading 6

2. Text Emphasis

**Bold Text** or __Bold Text__
*Italic Text* or _Italic Text_
***Bold and Italic***
~~Strikethrough Text~~
`Inline code snippet`

3. Lists & Task Checkboxes

Bullet (Unordered) Lists

- Item Alpha
- Item Beta
  - Nested sub-item
  - Nested sub-item
- Item Gamma

Numbered (Ordered) Lists

1. First step
2. Second step
3. Third step

Interactive Task Lists (GFM)

- [x] Completed task item
- [ ] Pending task item
- [ ] Research documentation

4. Links and Images

[Link Text](https://example.com)
[Link with Title](https://example.com "Hover Title")
![Image Description](https://via.placeholder.com/600x300.png "Alt preview")

5. Blockquotes

> Markdown is a lightweight markup language designed for plain-text readability.
> 
> Multiple paragraphs can be quoted with repeated arrows.
